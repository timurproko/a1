# Change delivery

Read and follow [Shared delivery rules](../../../docs/delivery-rules.md), using this repository's entry in [Delivery adapters](../../../docs/delivery-adapters.json). These are the policy owner; this skill supplies operational routing only.

| Operation | Command syntax and operational detail |
| --- | --- |
| Planning, implementation, validation, finalization, integration, handoff | [Delivery runbook](../../../docs/openspec-archive-automation.md) |
| Checkout creation, resume, attachment and runtime adapters | [Worktree protocol](../../../docs/architecture/project-structure.md#development-worktrees) |
| Cleanup, export decisions, ownership and recovery | [Local cleanup](../../../docs/local-worktree-cleanup.md) |

The shared rules' R01-R20 govern scope, authorization, progress, readiness and preservation. OpenSpec's own skills and framework remain unchanged.
