## 2. Native roles

- [ ] 2.1 Add `src/roles/registry.rs` (new file): the milestone-2 tab record fields from design Decision 8, written only under the registry-writer lease and current epoch through milestone 1's durable atomic replacement; reject a mutation when the lease or epoch is not current. Unit tests on all three platforms cover commit-before-acknowledge, lease loss, epoch mismatch, and the absence of credentials, environment values, and terminal content in the written file.
- [ ] 2.2 Add credential handling to `src/roles/registry.rs` or a new `src/roles/credentials.rs`: owner-only client-token and profile-secret files, and `HMAC-SHA256(secret, role ‖ tabId ‖ incarnation)` derivation. Tests: derivation is stable across restarts, differs per role, tab, and incarnation, and files are owner-only (ACL on Windows, `0600` in a `0700` directory on macOS and Linux).
- [ ] 2.3 Add `src/roles/server.rs` (new file) and the `server --detach` subcommand: lease and epoch at start, endpoint bind after the lease, handshake with client token, `already-running` when another server answers, `blocked` when the endpoint is silent and the lease is held, verified adoption of a recorded holder at start (credential, pid, native start identity, boot identity), one attached client at a time with a refusal message for a second, and exit 10 minutes after no tab and no client. Hermetic tests per platform use `A1_TABS_ENDPOINT` and temporary `A1_*_DIR` overrides for: concurrent starts (exactly one server), blocked start (no signal sent), pid reuse (no adoption), adoption after a server kill, and a second-client refusal.
- [ ] 2.4 Add `src/roles/holder.rs` (new file) and the `holder` subcommand, started by the server through milestone 1's fixed-role launch: one PTY (ConPTY on Windows), the tab child in its own kill-on-close job on Windows and its own process group on macOS and Linux, a continuous reader thread feeding one `GhosttyTerminal` with bounded scrollback, query answers from the model, a writer thread with a 4 MiB bounded queue and whole-paste admission, and `holder.ready`, surface patches, and `holder.exit`. Tests per platform with a fake child: output continues to be absorbed with no client attached; an over-capacity paste is rejected with no prefix delivered; admitted input arrives in order; DA and CPR are answered by the holder; a child exit produces `holder.exit` and the holder exits.
- [ ] 2.5 Add the single-slot render lane in the server: a newer patch set replaces an unsent one, a drained client receives a full surface, and the holder is never blocked by the client. Test with a client that stops reading: the holder's fake child keeps writing and the client receives a full current surface when it resumes.
- [ ] 2.6 Add `src/roles/attach.rs` (new file) and the `attach` subcommand: save the outer state; enable raw mode, the alternate screen, bracketed paste, focus events, SGR mouse, and synchronized output; enable the kitty keyboard protocol only after a positive 200 ms query; compose row 0 (one chip with status glyph and `agent`) and rows `1..N` with the existing damage-aware composer; size the tab PTY `cols × (rows − 1)`; offset mouse rows by one; forward OSC 52, OSC 8, and cursor shape; never forward BEL; restore exactly what was enabled on detach or a handled error and print `1 tab still running · run a1 to return`. Tests per platform drive the attach role over a pseudoterminal fixture and assert the emitted enable and restore sequences, the strip row, the mouse offset, and that BEL is not written.
- [ ] 2.7 Implement double-`Ctrl+C` detach in the attach client with the interval passed by Node: forward the first press encoded for the child's mode, consume a second press within the interval, and forward a press after the interval. Cover legacy `0x03`, kitty-encoded `Ctrl+C`, and Windows console key events. Tests assert the child receives exactly one `Ctrl+C` for a fast double press and two for a slow one.
- [ ] 2.8 Remove `--run`, `--probe-2x2`, `--topology-2x2`, and the fixed 2×2 layout from `src/main.rs` and `src/workspace.rs`; keep `--probe`, `--probe-scroll`, `--probe-selection`, and `--probe-input`. Update `scripts/development/run-terminal-host-probe.mjs`, `scripts/development/run-terminal-host.mjs`, the `proof:terminal-host` script in `package.json`, and `native/terminal-host/README.md` to the role subcommands. Prove with `npm run test:terminal-host` in the three-platform CI job.
- [ ] 2.9 Add a role integration test (new, under `native/terminal-host/tests/`) that runs server, holder, and attach with a scripted fake A1 child on each platform: create the tab, type, detach, let the child write while detached, kill the launching tree (Windows job close; `SIGHUP` to the session on macOS and Linux), reattach, and assert the retained surface contains the detached output and that input reaches the child. Run it in the terminal-host CI job on Windows x64, macOS, and Linux.
