## Why

The maintainer approved the seven-stage scope and explicitly requested all stages in the current interaction; optimization must retain every unique behavior, failure contract, runtime lane, and exact-package boundary.

## What Changes

- Add reproducible test-cost and coverage inventory reporting against current source and existing CI evidence.
- Deduplicate full rendering/input captures while retaining smoke-only assertions.
- Narrow reviewed PR ownership subareas with conservative fallback and changed-test/shared-support protection.
- Reduce fixture initialization and independent CLI capture process overhead without sharing mutable scenario state.
- Audit remaining overlap and consolidate only equivalent checks with replacement coverage recorded.
- Remove demonstrated duplicate exact-package preparation work within existing lane authority.
- Harden orchestration and document ownership, measurable savings, and remaining bottlenecks.

None. Existing continuous-integration and isolated-regression-testing safety requirements remain unchanged.
