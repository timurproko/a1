# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Herdr text copy submits once through the terminal route without host-native or platform writes.
- Supplied cross-machine text inserts exactly once without native clipboard acquisition.
- Valid raw Herdr screenshots without conventional remote markers become usable image attachments.
- A single supplied supported image file contributes its prepared image bytes exactly once on submission.
- Empty or unavailable screenshot acquisition reports retry feedback without losing later typing.
- Known-remote raw paste stays blocked, and failed supplied-image preparation never triggers native fallback.
- Ambiguous markerless remote raw gestures retain documented host-image-only access, not verified viewer ownership.
- Image limits, ordered reservations, cancellation, undo, and history attachment recovery retain bounded behavior.
