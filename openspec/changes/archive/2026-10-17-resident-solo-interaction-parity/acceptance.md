# Conditional implementation acceptance

Verdict: accepted only when an authorized human manually merges the containing exact pull-request head after required current-head validation, or personally enables native auto-merge for that unchanged head and GitHub integrates it after the validation succeeds.

The maintainer integration decision accepts these scenarios:
- Typing, modified keys, Alt chords, focus, pointer input, and pastes reach a resident tab as the same bytes the child would receive under direct `a1 solo`, including Ctrl+Enter and combining characters on Windows.
- One Ctrl+C reaches the viewed agent; a second press inside the clear/exit interval detaches and restores the terminal, including any cursor shape the agent set, while every agent keeps running.
- Copying from a resident tab places the text on the system clipboard once, and a hidden tab never writes the clipboard.
- Customized `keybindings.json` tab shortcuts are dispatched, labelled in tab menus, and listed under `/hotkeys` exactly as resolved, and a key an A1 action owns stays with that action.
- Several agents keep streaming while hidden, and switching tabs shows each tab's current output without flashing the previous tab's body under the new chip.
- A client that stops reading never delays another client's input or the server's maintenance answers.
