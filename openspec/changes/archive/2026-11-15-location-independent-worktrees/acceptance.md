# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- A session started outside Git can enter an explicitly selected repository or attach an absolute task worktree without restarting.
- Switching worktrees reloads trusted project instructions, settings, skills, and extensions while preserving conversation and writer ownership.
- Failed or cancelled transitions preserve prior ownership and prevent ordinary work under mismatched project resources.
- Explicit controls recover invalid attachments without deleting files, branches, or another session's claims.
- Completion restores startup context and runs declared cleanup only from the selected repository primary checkout after requesting tools exit.
