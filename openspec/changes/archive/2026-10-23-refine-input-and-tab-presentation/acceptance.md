Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Resident launch hides the outer cursor immediately, and bare reattach highlights the first running Agent without overriding explicit targets.
- The main prompt has one leading blank cell while auxiliary Agent and Settings text inputs remain marker-free.
- The live Tab bar position setting moves the complete resident strip, child, overlay, pointer, and cursor geometry between the top and bottom edges.
- Tab dragging keeps a stable insertion preview, reorders once on valid release, and leaves durable order unchanged for cancelled, stale, or no-op drops.
