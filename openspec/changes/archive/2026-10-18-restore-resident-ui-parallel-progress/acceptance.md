# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Three concurrent real Agent tabs continue generating, rendering, and animating before any turn settles, including while hidden or detached.
- Child synchronized-output transactions become one coherent committed presentation, and malformed transactions recover locally within 250 ms.
- Switching and resize present the requested tab’s complete current surface without stale geometry, blank intermediate frames, or full-body repaint for unchanged rows.
- Input after a switch or tab creation stays bound to its requested target while unrelated streaming tabs and strip animations continue progressing.
- Resident reconstruction preserves styled cells, hyperlink targets and IDs, cursor and terminal modes, and authorized once-only clipboard effects.
- Exact native fixtures compare direct and resident intermediate Ghostty state and reject isolated stage stalls, fragmented incoherence, slow-client freezes, or lost observations.
