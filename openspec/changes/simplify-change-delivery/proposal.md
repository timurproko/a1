## Why

Delivery ties remote planning and local checkout disposal to implementation and acceptance machinery, preventing useful work from other directories or machines. Contradictory instructions and rigid progress/readiness rules add friction without strengthening preservation or protected integration.

## What Changes

- Allow analysis, remote PR administration and real planning-only draft commits without a clone, worktree, attachment, dependency setup or cleanup sweep.
- Keep repository/branch/history/change/PR as durable task identity; resume an owned implementation checkout on whichever machine does the coding.
- Add explicitly requested local-only removal for published open-PR checkouts with fresh commit-containment and content/ownership checks; preserve remote work and retain local branches by default.
- Separate handoff, verified publication, optional cleanup release, local removal, delivery acceptance and remote abandonment.
- Replace per-outcome push barriers and lexical body gates with truthful checkpoints, material-scope approval, structural readiness and an explicit hold.
- Preserve protected exact-candidate integration and legacy records; exclude authority-changing docs from unattended integration.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- change-delivery-workflow: portable planning, authorization, progress, scratch, pause/resume and owned procedure guidance.
- session-worktree-recovery: existing-branch adoption and safe runtime local-removal settlement.
- local-worktree-cleanup: preservation-based local removal, truthful handoff and compatible bookkeeping.
- project-structure-governance: implementation isolation without machine-bound planning or mandatory retention.
- openspec-acceptance-review: meaningful acceptance lists without arbitrary count limits, preserving exact binding.

## Impact

Lifecycle/CLI/composition/tool integration; scripts/governance cleanup, readiness/body and docs integration; focused tests; AGENTS.md, delivery skill, runbooks and OpenSpec context. This draft authorizes no implementation, hosting apply, workflow activation, branch deletion, merge, private export or existing PR migration.
