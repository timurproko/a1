# @timurproko/a1-install

Dependency-free installer for [`@timurproko/a1`](https://www.npmjs.com/package/@timurproko/a1).

Release:

```sh
npx -y @timurproko/a1-install
```

Develop:

```sh
npx -y @timurproko/a1-install --develop
```

Preview number:

```sh
npx -y @timurproko/a1-install --develop 107
```

Exact preview:

```sh
npx -y @timurproko/a1-install --develop 0.1.8-dev.107
```
